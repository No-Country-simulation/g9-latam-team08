## Temas tratados

### 1. Avances del Equipo de Ciencia de Datos

El equipo presentó los avances alcanzados en la elaboración del dataset, compartiendo la estructura sobre la cual se encuentra trabajando.

Se informó que la definición del dataset aún requiere algunos ajustes antes de considerarse finalizada y se asumió el compromiso de concluir esta actividad durante la semana.

Asimismo, se solicitó mantener actualizado el tablero Trello del Equipo de Ciencia de Datos, especialmente las listas **Ideas Confirmadas** y **En Desarrollo**, con el fin de facilitar el seguimiento del proyecto.

Actualmente se registraron como **Ideas Confirmadas** las siguientes funcionalidades:

- Clasificación de gastos esenciales y no esenciales.
- Identificación de gastos mensuales correspondientes a servicios de suscripción (streaming).
- Generación de recomendaciones orientadas al cumplimiento de metas de ahorro.

Se destacó que estas funcionalidades amplían el alcance del análisis financiero y aportan mayor valor al usuario final.

### 2. Avances del Equipo de Desarrollo

El Equipo de Desarrollo informó que actualizó su tablero Trello incorporando nuevas actividades.

Como **Ideas Confirmadas** se registró:

- Categorización de datos.

En la lista **En Desarrollo** se encuentran las siguientes tareas:

- Desarrollo de la API REST.
- Diseño de la interfaz de usuario en Figma.
- Desarrollo de la aplicación web.

Asimismo, se confirmó que el MVP contará con una aplicación web responsive compatible con equipos de escritorio y dispositivos móviles.

### 3. Confirmación del alcance del MVP

Se confirmó que el MVP estará compuesto por los siguientes componentes:

- Modelo de Ciencia de Datos.
- API REST.
- Integración con Oracle Cloud Infrastructure (OCI).
- Aplicación web responsive para demostrar el funcionamiento de la solución.
