## Temas tratados

### 1. Definición del usuario objetivo

Se acordó que el usuario principal del proyecto será una persona que desea comprender mejor su situación financiera, organizar sus ingresos y gastos, identificar sus hábitos de consumo y recibir recomendaciones claras que le permitan mejorar su salud financiera y tomar mejores decisiones sobre el manejo de su dinero.

Asimismo, se estableció que, aunque la solución podrá integrarse posteriormente con fintechs o billeteras digitales mediante una API REST, el desarrollo inicial estará orientado a resolver la necesidad del usuario final.

### 2. Enfoque del MVP

Se definió que el MVP estará centrado en brindar valor al usuario final mediante una solución que permita:

- Ingresar información financiera.
- Registrar o cargar transacciones.
- Clasificar los gastos.
- Analizar hábitos de consumo.
- Identificar el perfil financiero del usuario.
- Generar recomendaciones simples y comprensibles.

Posteriormente, la solución será integrada mediante una API REST y servicios de Oracle Cloud Infrastructure (OCI), permitiendo su utilización por otras aplicaciones o plataformas.
