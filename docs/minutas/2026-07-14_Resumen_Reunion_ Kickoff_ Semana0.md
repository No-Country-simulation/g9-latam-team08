## Temas tratados

### 1. Revisión del desafío

Como actividad inicial, el equipo realizó una lectura conjunta del planteamiento del hackathon con el propósito de comprender el contexto del proyecto y alinear una visión compartida sobre el desafío.

Durante la revisión se analizaron los siguientes aspectos:

- Problema planteado.
- Descripción del proyecto.
- Necesidad del cliente.
- Objetivo general de la solución.

Esta actividad permitió aclarar dudas iniciales sobre el alcance del proyecto y establecer una base común para las siguientes etapas de planificación.

### 2. Investigación de referencias

Con el fin de comprender mejor el problema y conocer soluciones similares, se acordó realizar una investigación de proyectos de referencia.

Se definió que:

- Lucía revisará proyectos y documentación relacionada con el desafío.
- Magalí investigará productos similares y posibles funcionalidades que puedan servir como referencia para el diseño de la solución.

Los resultados de esta investigación serán compartidos y analizados en la siguiente reunión.

### 3. Organización del equipo

Como primera aproximación a la organización del trabajo, se acordó dividir el proyecto en dos equipos principales:

- **Equipo de Ciencia de Datos**
- **Equipo de Desarrollo**

La conformación definitiva de los integrantes y la asignación de responsabilidades quedaron pendientes para la siguiente reunión.

### 4. Gestión del proyecto

Se acordó utilizar **Trello** como herramienta para la planificación, organización y seguimiento del proyecto.

Para facilitar la gestión del trabajo se definió la creación de tres tableros:

- **Trello General**, administrado por **Yanucelly Moreira (Project Manager)**.
- **Trello Equipo de Ciencia de Datos**, administrado por **Matías Bueno (Data Engineer)**.
- **Trello Equipo de Desarrollo**, administrado por **Alan Joel Romero (Software Engineer)**.

### 5. Dataset

El equipo analizó la necesidad de construir un conjunto de datos que permitiera desarrollar el modelo de Ciencia de Datos.

Como propuesta inicial, se planteó elaborar un dataset propio siguiendo los lineamientos establecidos por el hackathon.

Quedaron pendientes las siguientes definiciones:

- Responsables de la construcción del dataset.
- Estructura del conjunto de datos.
- Estrategia para su elaboración.

## Acuerdos alcanzados
