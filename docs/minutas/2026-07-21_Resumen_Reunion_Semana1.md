## Temas tratados

### 1. Presentación de la estructura definitiva del dataset

El Equipo de Ciencia de Datos presentó nuevamente la estructura del dataset para los integrantes del Equipo de Desarrollo que no pudieron asistir a la reunión anterior.

Se revisaron las decisiones relacionadas con la clasificación de los gastos y se confirmó el tratamiento de los siguientes conceptos:

- Gastos esenciales y no esenciales.
- Gastos correspondientes a servicios de suscripción (streaming), los cuales serán tratados de forma independiente para permitir que el sistema genere recomendaciones periódicas sobre la conveniencia de mantener o cancelar dichos servicios.

Asimismo, se informó que con esta reunión finaliza la etapa de definición del dataset, dando inicio al desarrollo del modelo de Machine Learning.

### 2. Avances del Equipo de Desarrollo

El Equipo de Desarrollo informó que el desarrollo inicial del proyecto se realizará utilizando una base de datos local.

Además, se indicó que continúan las investigaciones necesarias para obtener las credenciales y configurar el acceso a Oracle Cloud Infrastructure (OCI).

### 3. Seguimiento del proyecto

Como parte del seguimiento general del proyecto, la Project Manager informó que fueron compartidas las propuestas de organización de los tableros Trello para los equipos de Ciencia de Datos y Desarrollo.

Se solicitó mantener actualizadas las tarjetas incorporando, como mínimo, la siguiente información:

- Responsable.
- Fecha estimada.
- Colaboradores.
- Estado de avance.

El objetivo es facilitar el seguimiento de las actividades y mejorar la coordinación entre los equipos.
