## Estructura de las minutas

Las minutas registran, según los temas abordados en cada reunión:

- Objetivo de la reunión.
- Participantes y ausentes.
- Seguimiento de avances.
- Temas tratados.
- Acuerdos alcanzados.
- Pendientes.
- Próximos pasos.
- Próxima reunión, cuando corresponda.
- Cierre.
