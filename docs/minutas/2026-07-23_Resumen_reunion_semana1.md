## Temas tratados

### 1. Avances del Equipo de Ciencia de Datos

El equipo confirmó que el proyecto trabajará con dos datasets:

- Dataset para la clasificación de gastos.
- Dataset para el análisis del perfil financiero.

Asimismo, se informó que la etapa de definición de ambos datasets quedó finalizada y que el equipo comenzó el desarrollo de los modelos de Machine Learning.

También se indicó que el tablero Trello del Equipo de Ciencia de Datos continuará actualizándose conforme a la estructura acordada para el seguimiento de las actividades.

### 2. Avances del Equipo de Desarrollo

El Equipo de Desarrollo informó que continúa trabajando en:

- Implementación de la API REST.
- Diseño de la interfaz web responsive en Figma.

Estas actividades corresponden a componentes fundamentales del MVP y avanzan de manera paralela al desarrollo de los modelos de Machine Learning.

### 3. Estado de Oracle Cloud Infrastructure (OCI)

El responsable del componente de Oracle Cloud Infrastructure (OCI) informó que continúa investigando el proceso de acceso y los requisitos necesarios para la futura integración del proyecto con OCI.

Por el momento no se identifican bloqueos que requieran apoyo adicional.
