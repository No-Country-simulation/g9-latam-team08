# 📊 Finance AI – Asistente Inteligente de Salud Financiera

## Gestión del Proyecto

---

## Objetivo

Describir la organización, planificación, coordinación y seguimiento realizados durante el desarrollo del proyecto, documentando la metodología de trabajo, la gestión de las actividades y la colaboración entre las distintas áreas del equipo durante el Hackathon Alura + Oracle ONE.

---

## Alcance

La gestión del proyecto comprende:

- Organización del equipo.
- Planificación del trabajo.
- Seguimiento de actividades.
- Coordinación entre las áreas.
- Gestión de reuniones.
- Gestión documental.
- Gestión de riesgos.
- Seguimiento de entregables.
- Coordinación de la integración del MVP.

---

## Metodología de Trabajo

El equipo adoptó una metodología de trabajo ágil basada en **Kanban**, utilizando **Trello** como herramienta principal para la planificación, organización, seguimiento y control de las actividades del proyecto.

Las tareas fueron organizadas mediante un backlog y gestionadas a través de tableros con estados de avance, permitiendo dar seguimiento continuo al desarrollo del MVP, facilitar la coordinación entre las distintas áreas y priorizar las actividades de acuerdo con las necesidades del proyecto.

---

## Organización del Equipo

El proyecto fue desarrollado por un equipo multidisciplinario integrado por especialistas en Ciencia de Datos, Ingeniería de Datos, Backend, Frontend, Full Stack, Software Engineering y Project Management.

Cada integrante asumió responsabilidades específicas dentro de su área, trabajando de manera colaborativa para alcanzar los objetivos definidos para el MVP.

---

## Organización por Componentes

El proyecto fue organizado en los siguientes componentes:

- Ciencia de Datos.
- Backend.
- Frontend.
- Oracle Cloud Infrastructure (OCI).
- Gestión del Proyecto.

Cada componente contó con responsables específicos y trabajó de forma coordinada para desarrollar e integrar las funcionalidades del MVP.

---

## Herramientas de Gestión del Proyecto

Para la organización y coordinación del proyecto se utilizaron las siguientes herramientas:

- Trello.
- GitHub.
- GitHub Desktop.
- Discord.

---

## Planificación del Proyecto

La planificación del proyecto se realizó de manera incremental, definiendo inicialmente el alcance del MVP, organizando el backlog del proyecto y distribuyendo las actividades entre las distintas áreas.

Durante el desarrollo se realizó un seguimiento continuo del avance, permitiendo reorganizar tareas y prioridades cuando fue necesario para cumplir con los objetivos establecidos.

---

## Seguimiento del Proyecto

El seguimiento del proyecto se realizó mediante:

- Reuniones periódicas del equipo.
- Elaboración de minutas de reunión.
- Actualización del Trello General.
- Seguimiento por componentes.
- Revisión continua de la documentación.
- Seguimiento de GitHub y del avance de cada área.

---

## Gestión Documental

La documentación del proyecto fue organizada siguiendo un estándar común para todas las áreas.

Se definieron:

- README principal.
- README por área.
- Documentación técnica.
- Documentación de gestión.
- Minutas de reunión.
- Documentos de control y revisión.
- Estructura documental común.

---

## Gestión de Riesgos

Durante el desarrollo del proyecto se realizó un seguimiento continuo de los riesgos identificados.

Entre los principales riesgos gestionados se encontraron:

- Ausencia temporal de integrantes.
- Retrasos en la integración entre componentes.
- Dependencias entre áreas.
- Coordinación de los entregables finales.

Cuando fue necesario, el equipo reorganizó actividades y redistribuyó responsabilidades para asegurar la continuidad del desarrollo del MVP.

---

## Gestión de Entregables

Los entregables fueron planificados y organizados de forma progresiva durante el desarrollo del proyecto.

Se definieron como entregables principales:

- Documentación del proyecto.
- Herramientas y Tecnologías.
- Enlaces del Proyecto.
- Manual de Usuario.
- Presentación (Pitch).
- Video Demo.
- Repositorio GitHub.

Antes de su publicación, todos los entregables serán revisados y validados por el equipo.
