# Documentación del Proyecto

Esta carpeta contiene la documentación funcional, técnica y de gestión del proyecto desarrollado durante el Hackathon Alura + Oracle.

La documentación está organizada por áreas con el objetivo de facilitar su consulta, mantenimiento y actualización durante el desarrollo del proyecto.

---

## Contenido

- Documentación General
- Documentación Técnica
- Documentación de Usuario
- Minutas de Reunión
